1. 프로젝트 개요

GitHub Pages 기반 정적 포트폴리오 사이트로, 별도 서버 없이 무료 호스팅합니다.

목적

GitHub에 공개된 17개 프로그램을 포트폴리오 형식으로 소개. 방문자가 각 프로그램의 목적·기능·기술 스택·GitHub 링크를 한눈에 파악할 수 있도록 구성합니다.

대상 독자

채용 담당자·협업 파트너·동료 개발자. 디지털 명함 역할. 모바일 우선(한국 웹 트래픽 70%+ 모바일).

성공 기준

  • · 17개 저장소 카테고리별 정리
  • · 각 카드에 설명·언어·GitHub 링크 포함
  • · GitHub Pages 정상 렌더링, 반응형
  • · Lighthouse 접근성·성능 90+

호스팅

GitHub Pages (정적, 무료). 저장소: Donian-kor/Donian-kor.github.io 또는 homepage. 브랜치 main → root.

프로젝트 섹션 내부 구조

  • · 카테고리 탭 필터: 전체 / Android 앱 / Python 데스크톱 / 웹·PWA / Windows 도구 / 포크·참여
  • · 프로젝트 카드: 스크린샷(앱/프로그램 화면) + 제목 + 한 줄 설명 + 언어 배지 + GitHub 링크 + (데모 있는 경우) 데모 링크
  • ↳ 스크린샷: assets/images/projects/<repo-name>.webp / projects.json의 screenshot 필드로 관리 / 없으면 언어별 아이콘 또는 placeholder 폴백 / WebP + lazy load + decoding="async"
  • · 데이터 관리: projects.json (또는 JS 배열)로 분리, 카드는 JS 동적 렌더링 → 신규 프로젝트 추가 시 데이터만 수정

2.4 유지보수성 & 2.5 반응형 설계

저장소가 늘어나거나 삭제될 때 쉽게 관리하고, 모든 모바일 기종에서 반응형으로 동작하도록 설계합니다.

유지보수성 (추가/삭제 용이)

  • · 데이터와 뷰 분리: 프로젝트 정보는 projects.json 단일 파일에만 저장
  • · 추가 절차: projects.json에 항목 1개 추가 → 페이지 새로고침으로 자동 반영
  • · 삭제 절차: projects.json에서 항목 1개 제거 → 카드 자동 사라짐
  • · 카테고리: 카테고리 목록도 데이터 파일에서 관리, 탭 UI 자동 생성

반응형 설계 (모바일 기종 무관)

  • · Mobile-first: 375px부터 설계, 큰 화면으로 확장
  • · 브레이크포인트: 375 / 414 / 768 / 1024 / 1440px
  • · 레이아웃: CSS Grid (grid-cols-1 sm:grid-cols-2 lg:grid-cols-3)
  • · 컨테이너: max-w-7xl mx-auto px-4 sm:px-6 lg:px-8
  • · 전체 높이: min-h-[100dvh] (h-screen 금지)
  • · 터치 타겟: 최소 44×44px, 버튼 간 8px+
  • · 가로 스크롤 금지: 모든 섹션에서 horizontal scroll 없음
  • · 테스트 기종: iPhone SE, iPhone 14 Pro, Galaxy S23, iPad, 데스크톱
